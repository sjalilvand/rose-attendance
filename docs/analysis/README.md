# فاز ۱ ـ تحلیل نهایی سامانه رز سفید

این پوشه تحویل‌دادنی‌های فاز ۱ (تحلیل نهایی) است و بر مبنای **سند جامع نیازمندی‌ها نسخه ۲٫۱ (مصوب)** تهیه شده است. هر تصمیم در این اسناد یا ترجمه مستقیم تصمیم مصوب سند است یا «پیشنهاد تکمیلی» مشخصی برای تثبیت در فاز ۲؛ هیچ موردی برخلاف سند مصوب نیست.

| سند | محتوا |
|---|---|
| [`01-data-model.md`](01-data-model.md) | مدل داده نهایی: اصول، ERD، مشخصات کامل جدول‌ها، Enumها، نگهداری داده |
| [`schema.sql`](schema.sql) | اسکلت DDL PostgreSQL (معادل آینده Migrationهای Django) |
| [`02-calculation-rules.md`](02-calculation-rules.md) | قواعد محاسبه کارکرد: خط لوله، جفت‌سازی، زمان مؤثر، قواعد نسخه‌دار، شبه‌کد، حالت‌های مرزی |
| [`03-screens.md`](03-screens.md) | طراحی صفحات: اصول UI، نقشه ناوبری، مشخصات S-01 تا S-08 و P-01 تا P-11، جریان‌ها، ماتریس نقش‌ها |

## چک‌لیست فاز ۱ (بخش ۳۲ سند)

| آیتم فاز ۱ | وضعیت |
|---|---|
| دریافت نمونه Excel واقعی | ⬜ در انتظار کارفرما |
| دریافت قوانین کارکرد (آیین‌نامه منابع انسانی) | ⬜ در انتظار کارفرما ـ ساختار `rule_sets` آماده بارگذاری است |
| تعیین مدیران و جانشین‌ها | ⬜ در انتظار سازمان |
| تصویب سیاست حذف و نگهداری | ✅ در نسخه ۲٫۱ مصوب شد |
| تعیین مرورگرهای PWA و نسخه‌های Android هدف | ✅ در نسخه ۲٫۱ مصوب شد (Chrome و Edge دو نسخه آخر + WebView) |
| مدل داده نهایی، قواعد محاسبه و طراحی صفحات | ✅ در این پوشه (پیش‌نویس ۰٫۱ برای بازبینی) |

پس از دریافت سه ورودی باقی‌مانده از کارفرما، این اسناد به نسخه ۱٫۰ فاز ۲ (تثبیت‌شده) ارتقا می‌یابند و پیاده‌سازی Django/React بر اساس آن‌ها شروع می‌شود.
