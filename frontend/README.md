# PWA پرسنل — سامانه حضور و غیاب رز سفید

وب‌اپ نصب‌شدنی (PWA) پرسنل با **React 18 + TypeScript + Vite**، راست‌به‌چپ و تمام‌فارسی، مطابق طراحی صفحات فاز ۱ (`docs/analysis/03-screens.md`) و مرورگرهای هدف سند ۲٫۱ (Chrome و Edge دو نسخه آخر + Android WebView).

## صفحه‌ها

| مسیر | صفحه | شرح |
|---|---|---|
| `/login` | ورود | JWT با قفل حساب پس از ۵ خطا (بخش ۶ سند) |
| `/` | ثبت تردد | دکمه ورود/خروج، انتخاب شعبه، پیش‌نمایش فاصله (یک‌باره)، کارت وضعیت امروز، صف آفلاین |
| `/history` | کارکرد | ردیف‌های روزانه ماه شمسی (تأخیر/استراحت/اضافه‌کاری/غیبت/مرخصی) |
| `/summary` | خلاصه ماه | ردیف‌های `monthly_summaries` با وضعیت موقت/قطعی/اصلاح‌شده |
| `/settings` | تنظیمات | اندازه‌گیری اختلاف ساعت، همگام‌سازی صف، خروج |

## معماری آفلاین (اصل قطعی ۲ سند)

- ثبت‌ها با شناسه `event_uuid` (crypto.randomUUID) ساخته می‌شوند؛ **رفتار تکرارپذیر** سمت سرور تضمین می‌کند ارسال مجدد اثر جدید ندارد.
- در نبود شبکه، ثبت در **IndexedDB** (`rose-offline/queue`) می‌ماند و با رویداد `online`، باز شدن اپ یا دکمه دستی، از طریق `/attendance/events/sync/` همگام می‌شود.
- اختلاف ساعت دستگاه با سرور در لحظه ثبت گزارش می‌شود (`clock_offset_minutes`) تا تصمیم `CLOCK_SKEW` (±۵ دقیقه) سمت سرور گرفته شود.
- **هیچ ردیابی مستمر GPS انجام نمی‌شود** — موقعیت فقط در لحظه ثبت پرسیده می‌شود و ثبت بدون موقعیت مجاز است.

## اجرای محلی

```bash
cd frontend
npm ci
npm run dev        # http://localhost:5173 — پراکسی /api به 127.0.0.1:8000
npm run build      # tsc --noEmit + vite build → dist/ + sw.js + manifest
```

بک‌اند را طبق `backend/README.md` روی پورت ۸۰۰۰ اجرا کنید. برای تست آفلاین: در DevTools تب Network حالت Offline را فعال کنید — ثبت‌ها در صف می‌مانند و با بازگشت شبکه خودکار همگام می‌شوند.

## نکات استقرار

- تصویر Docker دو مرحله‌ای است: build با node:22-alpine و سرو با nginx؛ `nginx.conf` مسیر `/api/` و `/ws/` را به سرویس `api` پروکسی می‌کند و `sw.js` را بدون کش می‌دهد.
- آدرس API با متغیر محیطی `VITE_API_BASE` (پیش‌فرض `/api/v1`) قابل تغییر است.
- آیکون‌های فعلی جایگزین موقتی‌اند؛ پس از دریافت هویت بصری نهایی، `public/icons/*` را عوض کنید.
